# GameStore - Sistema de Gestión con Excepciones

**Integrantes:** Cuellar Lucas y Santi De Soisa


## Descripción del negocio
GameStore es una plataforma digital de compra y venta de videojuegos físicos y digitales, destinada a gamers y coleccionistas.

## Problema que resuelve
El sistema valida de forma robusta las operaciones comerciales (como el registro de ventas, control de stock y alta de productos) utilizando excepciones personalizadas para evitar errores críticos de negocio (por ejemplo, intentar vender un juego sin stock, ingresar precios negativos o duplicar códigos de juego).

## Tema elegido
Clase 9: Excepciones. Lo elegimos para garantizar la robustez del software mediante el uso de `try/catch/finally` y excepciones personalizadas (`RuntimeException` o `Exception`).
